# 脚本编辑器与资源规范

## 简易向导与专业模式

脚本弹窗支持在顶部无损切换 **「简易向导」** 与 **「专业模式」**：

- **简易向导（4 步可视化）**：
  1. **队伍配置**：按星级 / 职介 / 宝具色快速筛选从者并指定助战位、御主礼装与性别。
  2. **助战与礼装**：选择助战模式、满破与技能要求，支持冠位 3 槽礼装可视化点选。
  3. **战斗技能轴**：按波次排布技能与宝具，直接展示 `assets/servant_skill/` 官方技能图标、游戏内官方技能名与中文效果注释（数据源 `data/skill_details.json`），支持添加及一键/确认删除波次并自动顺延重排编号。
  4. **保存与检查**：自动生成推荐脚本名并实时校对配置。
- **专业模式**：覆盖全部结构化控件与原始 JSON 编辑。脚本/策略旁的复制按钮可把当前预设载入新草稿（清空名称），保留全部扩展字段并受同名覆盖保护。

## 源码保真 JSON 编辑机制

预设详情接口同时返回解析结果与原始 `source` 文本；保存接口接受 `config`/`entries` 或 `source`（二选一），对非法 JSON、错误顶层类型、非有限常数和浮点溢出进行严格拦截。

前端引入了 `webapp/static/vendor/jsonc-parser.js`（MIT 许可，v3.3.1，esbuild 0.28.2 打包，严格 JSON 模式）做 AST 局部字节替换：
- 标量开关、队伍、助战筛选、助战礼装、结算、掉落、回合技能、宝具顺序、替补映射、条件策略与回合策略编辑均只替换目标字段，**不破坏无关字段的原始浮点写法、超大整数和历史扩展属性**。
- 若源 JSON 存在重复键（含转义别名），仅锁定存在歧义的对应控件并给出提示，不干扰其他字段编辑；所有修改在点击 **保存** 前均为草稿态，加载预设或保存过程中自动加锁并丢弃过期异步响应。

## 关键脚本字段与编辑器控件

- **队伍与御主**：6 个从者槽、助战槽 `assistIdx`、区服 `server`（`CH` / `CNTW` / `JP`）、御主礼装 `master_equip`（对应 `master_info.json` 保留前导零与 `0`）与性别 `master_sex`（0 女 / 1 男，预览通过 `/api/masters/image` 读取 `masterface/{outfit}_{sex}.png`）、编队验证槽 `usedServant`。
- **波次管理**：专业模式“Waves”区块支持追加波次/回合及删除末尾回合或最高波次（不重排其他波次键）；简易向导支持删除任意波次并自动顺延重排。列表上限 1,000 项。
- **宝具顺序与战后替补**：
  - 常规回合支持配置最多 3 个有序宝具。
  - `round{r}_turn{t}_replace` 映射站位 `"1"`–`"6"` 到来源槽 `1`–`6` 或 `null`。点击 **Auto-Calculate** 调用 `POST /api/settings/calculate-turn-replace`，自动推算换人、自爆宝具（阿拉什/信胜/草十郎/图坦卡蒙）、陈宫卖队友、鹤小姐/泳装克洛伊退场、哈贝喵 3 技能、战续次数（`will_nums`）与手动阵亡槽位，并同步更新 `usedServant`。
- **技能序列与特殊技能命令**（支持常规与额外回合，最多 1,000 条）：
  - **普通技能 / 敌方目标**：`[13, enemyPos]`（1–6）。
  - **御主换人**：三元数组选定前排（1–3）与后排（4–6）。
  - **令咒**：充能与回血令咒，保留原版标准命令名。
  - **宝具变色**：宇宙伊什塔尔 2 技能（Q/A/B）、卫宫 3 技能（A/B），沿用负数技能位格式。
  - **库库尔坎**：`["Kukulkan", skill, option]`（及 2 技能第 4 位目标），控制是否消耗 10 暴击星。
  - **三技能/命名字段变体**：支持 UDK-巴格斯特、BB 迪拜、静希草十郎（Q/A/B）、岸波白野（T/D/R）、梵高〔矿工〕（1 技能 Q/A/B）、但丁（2 技能 A/B）、玉兔（2 技能 All/One）、夏洛特·科黛（3 技能，需明确 `CH`/`JP` 区服）、芙洛拉（3 技能 T/D）。
  - **白野发牌需求**：`["Hakuno", skill, combinations]`（位置 1/4/7），支持普通卡码（`1B`）、标签码（`S0`）与组合码（`1BS0`），最多 1,000 组。
  - **条件技能块**：`["Start", mode, checks, ["np", ...]]` 与 `["End"]`，配合 `round{r}_turn{t}_condition` / `round{r}_extraCondition` 使用。
- **策略文件与回合策略**：每张卡支持类型、有序偏好码、暴击星上下限（0–10）与 `breakpoint`（不同从者断点）。应用策略预设到某回合时为值拷贝，不与原策略文件动态联动。

## 资源与自定义标签约定

- **基础目录**：识别模板在 `assets/`，配置与数据在 `data/`（脚本 `data/settings/`、策略 `data/strategy/`）。
- **自定义助战标签**：存于 `assets/assist/assist_tags/`，PNG 文件名编码源分辨率、裁切偏移与置信度阈值。被脚本引用时禁止删除。
- **自定义指令卡标签（`specialKeys`）**：通过 Tag Maker 的 **Command Cards** 截屏裁切，存于 `assets/battle/customCommandCard/`，按绑定顺序映射为 `S0`、`S1`…；仅允许解绑末尾且未被任何策略/技能/白野组合引用的标签，绝不静默重排已有索引。
- **掉落模板解析**：优先解析 `assets/drop/` 内的完整路径，仅当索引中文件名唯一时才允许裸文件名回退；路径遍历与越界软链接一律拒绝。
- **前端第三方许可**：本地工具栏图标来自 Lucide Static 1.43.0（许可见 `webapp/static/icons/LICENSE.txt`）；`jsonc-parser` 许可位于 `webapp/static/vendor/`。
