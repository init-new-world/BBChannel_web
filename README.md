# BBchannel Web

BBchannel 的本地 Web 控制台：提供设备连接、实时画面预览与触控、可视化脚本向导、全流程自动刷本及常用活动自动化。

> 项目仍在持续迭代中，首次使用新脚本或更换模拟器分辨率时，建议先开 **1 把** 观察运行情况再开启多把/清体。

## 快速开始

### 1. 安装依赖

需要 **Python 3.10+**，在 `web/` 目录下安装依赖：

```bash
python -m pip install -r requirements.txt
```

确认以下资源目录已就位（从 BBchannel 发行包复制或随仓库提供）：
- `assets/`：图像识别模板、从者头像、技能图标等素材
- `data/`：刷本脚本（`data/settings/`）、选卡策略（`data/strategy/`）及从者/礼装目录

### 2. 启动 Web 服务

```bash
python -m webapp
```

然后在浏览器打开：**http://127.0.0.1:8000**

> 如需从宿主机或局域网访问（例如运行在 WSL 中从 Windows 浏览器打开），可指定监听 `0.0.0.0`：
> ```bash
> python -m uvicorn --factory webapp.app:create_app --host 0.0.0.0 --port 8000
> ```
> **安全提示**：本服务面向本地信任环境设计、不含登录鉴权，请勿直接暴露到公网。

### 3. 四步上手刷本

1. **连接设备**：在左侧设备栏点击刷新并连接在线模拟器/设备（未自动发现时可直接输入 `IP:端口` 手动添加 ADB 设备）。
2. **确认画面**：开启顶部 **Live** 实时画面；如画面方向异常可用 `-90°` / `+90°` / `Auto` 校准；勾选 **触控** 即可在网页画面上直接点击、实时长按或拖动操作游戏。
3. **选择或新建脚本**：可直接选用 `data/settings/` 中已有脚本，或点击 **+ 向导新建脚本** 通过 4 步可视化向导选人、配礼装、点技能（也支持随时切换到 **专业模式** 精修 JSON）。
4. **开始运行**：在右侧 **刷本** 页签设置次数与苹果策略，停在助战/编队/战斗/结算任一界面，点击 **开始刷本** 即可自动衔接执行。

## 常见 FAQ

**Q：WSL 下怎么连 Windows 宿主机上的 MuMu 模拟器？**  
无需手动查宿主机 IP。默认开启 ADB 自动发现（`BBCHANNEL_ADB_SCAN_HOSTS=auto`），会自动读取 `/etc/resolv.conf` 中的宿主机地址并探测 `5555 / 16384 / 7555 / 62001` 等常见模拟器端口；若模拟器端口不在默认列表里，在左侧输入框直接填 `宿主机IP:端口` 添加即可。

**Q：选助战一直刷新选不到人怎么办？**  
多半不是头像没认出（底层会自动匹配该从者的全部再临阶段与灵衣头像），而是脚本里的助战筛选条件过严。优先检查：
- 主动/附加技能（被动）等级要求是否过高（例如不需要放宝具的拐把被动 2 设为 `0`）；
- 是否勾了 **仅好友**、**礼装满破**、或冠位 3 槽礼装约束太严；
- 点开底部事件日志可直观看到每一轮是否命中候选及被哪一项条件筛掉。

**Q：刷本中途停了或断网，可以接着续打吗？**  
可以。入口模式默认是 `current`（从当前画面继续），重开任务会自动识别当前处于助战、编队、战斗还是结算界面并接续；战斗中已内置断网重试弹窗处理，开启 `gameCrushRestart` 后闪退或卡死也能自动重拉游戏恢复。

**Q：怎么开启单步调试排查识别问题？**  
勾选界面上的 **Step debug**（或设置环境变量 `BBCHANNEL_DEBUG_STEP=1`），每次点击/滑动前会自动暂停，并将带识别框标注的截图与日志保存到 `runtime/debug/<job_id>/`。

**Q：界面支持中文/英文切换吗？**  
支持，点击顶部右上角语言选择器即可即时切换，选择会自动记住在浏览器本地。
